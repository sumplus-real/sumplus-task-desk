The working parts

The browser uses the official @modelcontextprotocol/sdk Client and StreamableHTTPClientTransport. A Node server uses McpServer and StreamableHTTPServerTransport. Protocol 2025-11-25 is negotiated at runtime. Six tools create a workspace, review a task, compare offers, quote, withdraw a pending quote and confirm a simulated approval.

What approval means

A quote binds the exact reviewed task, token ceilings, price mode, model and service line, budget, revision, expiry and SHA-256 catalogue snapshot. Confirmation recalculates on the server. Changed inputs, superseded quotes, expired quotes and quotes from another workspace are refused. A repeated confirmation returns the same receipt. No funds, real capacity reservation, model request or purchase exists.

Prices and limits

The included catalogue was fetched from the public Sumplus model directory, with its original timestamp and a content digest. A directory claim does not verify upstream model identity, availability, or response quality. A budget checks the estimated token cost for one specified workload. It is not an enforceable live execution budget and is not a promise about actual billing, taxes, fees, cache discounts or output quality. Zero-valued prices are never approvable.

Standard mode refuses a catalogue older than 24 hours. Historical snapshot replay explicitly uses the recorded prices at any date and labels quotes and receipts accordingly. This makes free, offline judging reproducible without disguising an old price as a live one. The operator can explicitly fetch a new directory with npm run catalogue:refresh and restart the server.

State and privacy

A random workspace ID is a bearer capability saved in this browser's localStorage. Treat it as private. State is stored in a local file, not a production account system. Receipts survive server restart; pending quotes are withdrawn on restart or reload. Up to 500 workspaces are retained; the oldest can be evicted. Export any receipts you want to retain. Do not enter personal information, secrets or real client prompts in this demonstration.

What was reused and what is new

The Sumplus brand and Model Desk catalogue comparison project existed before this sprint. Integer pricing, model-plus-line identity and capacity checks build on Model Desk's MIT code. New here: the procurement interface; server-owned task revisions and expiring quotes; explicit simulated approval; duplicate-safe receipts; persistent workspace state; official MCP SDK transport; browser MCP client; historical replay; positive and negative acceptance tests.

Prototype boundaries

This is a structured, deterministic workflow. It does not interpret arbitrary natural language with an AI model, recognize speech, connect to Amazon Alexa, or claim an official Alexa skill deployment. An LLM could later orchestrate these tools, but safe real purchasing would also require authentication, payment integration, full fee estimates, provider-enforced spending limits and reliable execution accounting.
